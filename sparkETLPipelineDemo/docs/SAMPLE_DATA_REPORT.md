# Sample data report

Generated by `scripts/SampleDataGenerator.java` (fixed random seed, so the output is always the same).
10 MongoDB collections x 100 documents = 1000 documents in database `bronze_db`.

Every bad document has exactly **one** planted problem, so the counts below are exact.
*Messy* values (extra spaces, wrong case, commas in numbers, `+91` phone prefix) are fixed by the
sanitizer, so those documents are still **valid**.
